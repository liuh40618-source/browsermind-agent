## [0.6.0] - Initial open-source release

### Added

- **Autonomous AI Agent** with think-act-observe loop for intelligent task execution.
- **Browser Automation** powered by Playwright for reliable, headless browser control.
- **Web Parsing** using BeautifulSoup combined with Readability for accurate content extraction.
- **Search Integration** via DuckDuckGo and Tavily for flexible web search capabilities.
- **FastAPI Backend** with WebSocket support for real-time streaming of agent actions and results.
- **React Three-Column Workspace UI** providing an intuitive, responsive user interface with task panel, browser viewport, and output console.
- **Multi-Turn Conversation Support** enabling iterative, context-aware interactions with the agent.
- **Task History with SQLite Storage** for persistent tracking and retrieval of past tasks and results.
- **Multi-LLM Support** with built-in adapters for OpenAI, DeepSeek, Qwen, and Zhipu language models.
